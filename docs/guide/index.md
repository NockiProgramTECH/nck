# Guide du langage

Le guide présente chaque notion de NCK avec de courts exemples exécutables. Lisez-le dans l'ordre si vous débutez,
ou utilisez la recherche (touche ++slash++) pour aller directement à une notion.

| Chapitre | Vous y apprendrez |
|---|---|
| [Variables, constantes et types](variables-types.md) | `variable`, `constante`, les types de base, l'inférence, les conversions |
| [Opérateurs et expressions](operateurs.md) | arithmétique, comparaisons, `et`/`ou`/`non`, priorités, `..`, `??` |
| [Textes](textes.md) | `f"…"`, échappements, `"""…"""`, fonctions de texte |
| [Conditions](conditions.md) | `si`/`sinon si`/`sinon`, `si … alors … sinon`, `selon`/`cas` |
| [Boucles](boucles.md) | `pour … dans`, `tantque`, `arreter`, `continuer`, plages |
| [Fonctions](fonctions.md) | paramètres typés, retour, valeurs par défaut, `...args`, fonctions anonymes, fermetures |
| [Listes](listes.md) | `liste<T>`, index, tranches, `appliquer`/`filtrer`/`reduire`, tri |
| [Dictionnaires](dictionnaires.md) | `dico<K, V>`, accès, parcours, `obtenir`, `fusionner` |
| [Types optionnels et nul](optionnels.md) | `T?`, affinement, `??` |
| [Classes et objets](classes.md) | champs, `soi`, `valider`, héritage, `parent`, `statique`, privé, abstraite, opérateurs, décorateurs |
| [Énumérations](enumerations.md) | `enumeration`, `selon` exhaustif |
| [Gestion des erreurs](erreurs.md) | `essayer`/`attraper`/`enfin`, `lever`, erreurs personnalisées |
| [Modules](modules.md) | `importer`, `comme`, `depuis … importer` |
| [Fichiers, JSON et dates](fichiers-json-dates.md) | lire/écrire des fichiers, JSON, horodatages, arguments du programme |
| [Style et bonnes pratiques](style.md) | conventions de nommage, organisation d'un projet |

La [référence complète du langage](../LANGAGE.md) regroupe toutes les règles sur une seule page.
